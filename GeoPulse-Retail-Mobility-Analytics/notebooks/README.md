# Notebooks

Suggested sequence:
1. `01_data_understanding.ipynb` — load approved data, inspect dimensions, schema, and sample rows.
2. `02_data_quality.ipynb` — missing values, duplicates, invalid values, and data-quality decisions.
3. `03_exploratory_analysis.ipynb` — analysis guided by the confirmed project questions.

Create notebooks after confirming the dataset format and schema. Avoid embedding sensitive records or credentials in notebook outputs.
