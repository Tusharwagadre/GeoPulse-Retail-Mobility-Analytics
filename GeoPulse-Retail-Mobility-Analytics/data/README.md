# Data directory

- `raw/`: keep original approved source files unchanged.
- `processed/`: store reproducible cleaned or transformed outputs.

Before adding data to GitHub, confirm that it is approved for sharing and contains no personal, confidential, or restricted information. The `.gitignore` excludes local data files by default.

Document the source, collection date, license/permission, row count, column count, and any filtering in `docs/DATA_DICTIONARY_TEMPLATE.md`.
